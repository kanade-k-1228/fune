# 港データの新規追加

新しい港を `data/ports/<id>.yaml` として作成するスキル。

データ仕様の全体は **[`../REFERENCE.md`](../REFERENCE.md)** を参照。港は項目が少ないので要点を以下に示す。

## スキーマ

```yaml
name: ["広島県", 阿賀] # [親エリア, 主名]。単独港は親エリアを "" にする（省略不可）
pos: [132.595859, 34.230267] # [経度 lon, 緯度 lat]
level: minor # 任意: major / minor / local
```

- スキーマは `.strict()`。**上記 3 キー以外を足すとエラー**
- `name` は必ず 2 要素タプル。第 2 要素は 1 文字以上

## 手順

1. **ID を決める** — `^[a-z0-9-]+$`（小文字英数字・ハイフン）、`data/ports/` で重複しない。港名のローマ字などが目安
2. **name を決める** — `[親エリア, 主名]`。親エリアは都道府県・島・市など、地図上で同名港を区別するためのグルーピング。単独で十分なら `["", 港名]`
3. **pos を取得** — 公式情報・地図サービスから桟橋/フェリーターミナルの座標を取り、**`[経度, 緯度]` の順**で記入する
   - ⚠️ Google Maps は「緯度,経度」表示。**順序を逆**にして入れること
   - 日本付近の妥当な範囲: lon ≈ 122〜154 / lat ≈ 24〜46。外れていたら取り違えを疑う
4. **level（任意）** — 規模感に応じて `major`（拠点港）/ `minor` / `local`（小規模）
5. **検証** — `pnpm validate` を実行して合格を確認する

## 注意

- 既に同じ港が別 ID で存在しないか `data/ports/` を確認してから追加する（重複登録を避ける）
- 座標は、その港を寄港地に持つ航路 YAML の `ports.<id>` と整合させる（同一地点を指すこと）
- 港を追加したら、それを使う航路（`add-line` / `update-line`）側で `ports` キーとして参照できる

## 報告フォーマット

```
## 追加
- data/ports/<id>.yaml （港名 / 座標 [lon, lat]）

## validate
- pnpm validate: ✓
```
